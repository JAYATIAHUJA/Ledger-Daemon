# Landing assets

landscape.png was generated with the built-in image generation tool for this project. Art direction: botanical watercolor and gouache, olive foliage at both sides, broad pale sky, sunlit countryside and cream house; no text or UI. Inspired by the user's supplied Vestris landing reference. Native HTML renders all interactive UI and copy.

Instrument Serif and DM Sans are bundled locally from Google Fonts. Their SIL Open Font Licenses are included alongside the fonts. No third-party font request is needed at runtime.

cli-demo.json contains stdout captured from a successful local `python -m ledger_daemon demo --seed 42 --n 500 --out out/landing-cli-recording` run. The final absolute filesystem path is omitted. Throughput belongs to this recording. The replay does not execute a command or represent a new live measurement. The app walkthrough embeds the running local controller and selects its actual tabs.
